# Actividad 5: Analizar una finalidad secundaria

## 1. Objetivo

Analizar si la empresa puede utilizar los datos de sus clientes para enviar promociones personalizadas, tomando en cuenta la privacidad, el uso adecuado de la información y la necesidad de limitar el acceso a los datos personales.

## 2. Procedimiento

Se revisó la nueva propuesta de la empresa para enviar promociones según la edad, ciudad y comportamiento de compra. Tambien se identificaron las preguntas que la empresa debería resolver antes de utilizar la información con este propósito, se revisó cuáles datos serían necesarios para personalizar las promociones y
se propusieron formas de limitar el acceso del área de marketing y proteger la información de los clientes.

## 3. Resultado

### 1. ¿El hecho de que la organización ya tenga los datos significa automáticamente que puede utilizarlos para cualquier finalidad?

No, que la empresa ya tenga los datos no significa que pueda utilizarlos para cualquier propósito. Primero debe revisar para qué fueron recopilados y si el nuevo uso es compatible con esa finalidad, también debe comprobar que exista una justificación adecuada para utilizar la información y que se cumplan las condiciones legales aplicables.

### 2. ¿Qué preguntas debería realizar la organización antes de implementar este tratamiento?

La organización debería hacerse las siguientes preguntas:

- ¿Se informó a los clientes que sus datos podrían utilizarse para enviar promociones?
- ¿La nueva finalidad es compatible con el propósito para el que se recopilaron los datos?
- ¿Existe una justificación adecuada para utilizar esta información?
- ¿Es necesario utilizar la edad, la ciudad y el comportamiento de compra para personalizar las promociones?
- ¿Qué datos se pueden dejar fuera para proteger mejor la privacidad?
- ¿Quién tendrá acceso a la información?
- ¿Durante cuánto tiempo se conservarán los datos utilizados para las promociones?
- ¿Cómo podrá la empresa atender las solicitudes de los clientes relacionadas con sus datos personales?

### 3. ¿Qué datos serían realmente necesarios?

Los datos necesarios dependerán de cómo se quiera realizar la campaña, odrían utilizarse la ciudad, un grupo de edad y la información relacionada con las compras.
El nombre, el correo o algún otro dato de contacto solo serían necesarios si se requiere identificar al destinatario y enviarle la promoción. 

### 4. ¿Necesitaría el área de marketing acceso directo a `clientes`?

No, el área de marketing debería recibir únicamente la información que necesita para preparar y realizar las campañas.

En lugar de darle acceso a toda la tabla `clientes`, la empresa podría crear una vista que muestre solamente los datos necesarios para las promociones.

### 5. ¿Qué controles técnicos podrían limitar la información entregada?

La empresa podría utilizar los siguientes controles:

Roles y permisos, Separación de datos, Datos agrupados, Registros de acceso, Retención limitada:
## 4. Análisis
La empresa no debería comenzar a utilizar los datos sin revisar primero si este nuevo uso está justificado y si cumple con las condiciones de privacidad aplicables.
Aunque la edad, la ciudad y el comportamiento de compra pueden ayudar a personalizar las promociones, no significa que sea necesario utilizar todos los datos disponibles, la empresa debe elegir únicamente los que realmente necesita y evitar exponer información que no tenga relación con la campaña.

## 5. Conclusión

Con esta actividad comprendí que una empresa no puede utilizar los datos personales para cualquier propósito solamente porque ya los tiene almacenados. Antes de darles un nuevo uso, debe revisar la finalidad, justificar qué información necesita y considerar las condiciones de privacidad aplicables.

# Actividad 7 — Derecho de rectificación

¿Cómo podría comprobarse que el cambio fue autorizado?

Se podría comprobar revisando que exista una solicitud del cliente y que se haya verificado su identidad antes de modificar el correo electrónico.

¿Debería registrarse quién realizó el cambio?

Sí, es importante registrar quién hizo el cambio, cuándo lo realizó y qué dato fue modificado, de esta manera, la empresa puede llevar un control de las modificaciones realizadas en la base de datos.

¿Por qué la trazabilidad será importante?

La trazabilidad permite conocer qué cambios se hicieron, quién los realizó y cuándo ocurrieron esto ayuda a revisar posibles errores, comprobar que las modificaciones se hicieron correctamente y detectar cambios que no estaban autorizados.
